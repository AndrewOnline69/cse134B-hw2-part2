Coursework and Projects

These projects represent some of my coursework at UC San Diego. Each gave me an opportunity to apply concepts from class and learn through practical work.

CSE 141L Processor

For CSE 141L, I worked on a custom processor called TriCore-9. The project involved connecting computer architecture concepts with a processor implementation.

CSE 110 Web Game

For CSE 110, I worked on a web game. This project provided an opportunity to apply software engineering concepts to a browser-based application.

CSE 134B Website

For CSE 134B, I am building this personal portfolio using semantic HTML. I planned the site with a fictional visitor persona, a site diagram, and low-fidelity wireframes. The website introduces my background, coursework, and interests while giving me practice organizing content with meaningful HTML elements.
